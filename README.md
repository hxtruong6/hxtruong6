  ### About me

  I'm a **backend engineer** by trade and an **AI researcher** by interest.

  **Day job — Backend.** I build production backend services with **NestJS + TypeScript**, backed by **PostgreSQL** and object storage on **MinIO/S3**. Comfortable with the full stack of REST/GraphQL APIs, auth, queues, caching, observability,
  containerization, and CI/CD.

  **Research — Trustworthy & uncertainty-aware ML:**
  - 🔬 **Open-Set Recognition (OSR) & OOD detection** — how models behave on inputs they were never trained for
  - 🏷️  **Multi-label classification** — Bayes-optimal prediction, evaluation metrics, pre-order structures over labels
  - 🕸️  **Graph embedding** — representation learning on dynamic graphs
  - 👁️  **Applied computer vision** — detection pipelines (YOLO family), image classification, fault detection

  For fun I tinker with distributed systems — e.g. [Tokimeki](https://github.com/ngocphat/tokimeki), a masterless filesystem-based job runner in Go for shared-FS clusters.

  I'm open to collaboration and currently **available for hire**.
